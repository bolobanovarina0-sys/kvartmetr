# КвартМетр: Платформа умного ЖКХ

    pip install -r requirements.txt
    python app.py          # http://127.0.0.1:5000

База `app.db` создаётся при первом запуске. Зарегистрируйтесь — получите демо-квартиру с пятью датчиками.
Для продакшена задайте переменную окружения SECRET_KEY.
Chart.js и шрифт Inter подключаются из интернета (cdnjs, Google Fonts).
